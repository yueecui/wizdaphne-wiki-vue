### 4.5 `index` 与图鉴号无关

手工 `index` 1~95 连续、按发布顺序排（无名 1~8 在最前，爱莉安诺特 94、夏莉莉妮雅第二风格 95 在最后）。
解包图鉴号是 67~69 / 2001~2069 / 9001~9006。两者不能混用：**前端排序用 `index`，跳转/外链用 `guide_no`**。

### 4.6 `characterRates` 的口径

手工 `characterRates` 95 条，形如：

```json
{ "name": "アリス - 雪袖の巫女", "str": 1, "rstr": 12.5, "iq": 1, "riq": 12.5, ... "rbase": 12.5 }
```

- `str` 等是 1/0/0.75 → 看起来是「每级成长点数」；
- `rstr` 等是 12.5 / 13.3333 / 19.2308 → 明显是**百分比占比**（12.5% = 1/8），72 条都是 12.5，说明大部分角色是均分。
- 解包对应的是 `Talent`（min/max）+ `CharacterGrowthRate`（`talent_id × job_lv` 的逐级 rate）。
- **建议**：不要直接复用 `r*`，改用解包的 `growth` + `talent` 重建；先把两边公式对齐再迁移。

### 4.7 `fate_type`（隐退后的「才能」）已找到

`fate_type` 就是角色隐退后产出的「XX 的才能」技能。链路：

```
Character.id
  → FateCharacterStatuses.character_id        (character_type = "Character::Character"，105 行，一角色一行)
  → FateCharacterStatuses.default_skill_id    (193015000 ~ 193015006)
  → Skill.name                                (「XX的才能」)
```

7 种才能与角色分布（本版本 105 行）：

| skill identification | 名称 | 手工 `fate_type` 写法 | 角色数 |
|---|---|---|---|
| 193015000 | 力量的才能（力の才能） | 力 | 29 |
| 193015001 | 智慧的才能（知恵の才能） | 智慧 | 21 |
| 193015002 | 信仰心的才能 | 信仰心 / 信仰 | 15 |
| 193015003 | 生命力的才能 | 生命力 / 生命 | 16 |
| 193015004 | 灵巧的才能 | 灵巧 | 16 |
| 193015005 | 敏捷的才能 | 敏捷 | 7 |
| 193015006 | 运气的才能 | 运气 | 1 |

验证：

- 菲利希娅 `202208630000` → `193015001` → 智慧的才能，与攻略站 `phyllisia` 页一致；
- 手工 95 条里**唯一没有值的是爱莉安诺特（「待补充」）**，解包给出「生命力的才能」（`193015003`），可直接补；

## 7. 复现方式

对照脚本目前是一次性分析，关键匹配规则：

1. 手工 `name_jp` 形如 `日文名 - 风格名`，先按 `\s+-\s+` 拆成 `(base, caption)`；
2. 解包按 `name_jp` 建索引，同一角色多行时用 `style.caption.name_jp` 与 `caption` 匹配，否则取 `style.is_default`；
3. 剩余未匹配行即 §2 的 10 行。

解包侧数据：`local_scripts/work/clean/character/characters.json`（105 行）与 `character_groups.json`（76 组）。
